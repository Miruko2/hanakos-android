## 这个 App 能做什么

**帖子与社区**
浏览图文帖子墙，发帖、评论、点赞、收藏，关注感兴趣的作者。帖子支持图片、话题分类与内容折叠，
带液态玻璃质感的卡片墙会把封面主色渲染成氛围背景。

**在线音乐**
站内音乐页收录精选歌单（以二次元、电音与同人音乐为主），接入网易云音乐与 QQ 音乐两路歌源，
支持搜索歌手、歌名、专辑并直接试听；封面以卡片墙铺开，点开即播。
还能把正在听的歌分享成一条帖子，别人点开就能跟着听。

**迷你播放器与波形**
离开音乐页后迷你播放器会常驻，封面下缘有一条跟随音频实时跳动的波形，
切歌、暂停、拖动进度都在手边。

**实时弹幕墙**
站内「实时弹幕墙」把当下在线的人说的话推到同一块屏幕上，App 上同样能看能发。

**私信与关注**
可以和社区好友一对一私信。在别人的主页上，关注之后那枚按钮会就地变成「私信」，少绕一层。

**个人主页与置顶帖**
自己主页的「帖子」栏能把一条帖子置顶到最前，方便把想让人先看到的内容固定住。
主页还有头图、关注/粉丝统计与关注名单。

**3D 虚拟家园与 AI 伙伴**
站内的 3D 虚拟家园与 AI 伙伴互动在 App 上同样可用 —— 养猫、换装、和伙伴聊天。

**分享海报**
把一条帖子生成带二维码的分享海报，直接发到站外。

## 常见问题

**有苹果（iPhone / iPad）版吗？**
没有独立的 iOS 应用。iOS 无法直接安装 APK，iPhone 与 iPad 用户可以用浏览器打开
<https://forum.hanakos.cc> 使用完整功能，也可以在 Safari 里把网页「添加到主屏幕」，
全屏运行、带桌面图标。

**为什么安装时提示「未知来源应用」？**
因为安装包没有上架应用商店，是官网直接分发的 APK。首次安装会提示风险，
在弹窗里允许从浏览器安装即可，不是安装包有问题。

**支持哪些安卓版本？**
需要 Android 8.0 及以上。当前版本 v0.72，安装包约 4.0 MB。

**电脑上能用吗？**
可以。用电脑浏览器打开 <https://forum.hanakos.cc> 就能使用全部网页功能，不必安装安卓包。

**这个仓库为什么没有源码？**
本仓库只用于分发编译好的安装包，应用源码不公开。使用中遇到的问题、功能建议，
欢迎到社区反馈：<https://forum.hanakos.cc>
